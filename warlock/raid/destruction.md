**What to press** (top to bottom: cast the first line that is ready):

Before the pull: cast Life Tap.

1. If time left in the fight ≥ 15s and mana % ≤ 75%: cast Potion
2. If time left in the fight ≥ 15s and mana % ≤ 60%: cast Demonic Rune
3. Use every other cooldown when ready
4. If time left in the fight ≤ 1.5: cast Shadowburn
5. If time left in the fight ≤ 3.5: cast Searing Pain
6. If time left on Bane of Agony ≤ cast time of Bane of Agony: cast Bane of Agony
7. If mana % < 10%: cast Life Tap
8. If not Curse of the Elements is up: cast Curse of the Elements
9. If time left on Corruption ≤ cast time of Corruption: cast Corruption
10. If time left on Immolate ≤ cast time of Immolate and time left in the fight ≥ 20s: cast Immolate
11. If Immolate is on the target: cast Conflagrate
12. Cast Incinerate
