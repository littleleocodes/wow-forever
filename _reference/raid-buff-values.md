# Raid buff values — what a support talent is worth to the raid

> Generated by `_reference/data/raidsim/buff_value.py` on 2026-09-26: every receiving spec's hand build ran in the community simulator (ElliotWood/Forever 40be98e for Forever, wowsims/classic 7779ebb for Classic Era) with the simulator's full buff set and with the one buff switched off; the difference is the buff's value to that receiver. Times the assumed number of beneficiaries it is the raid-wide value written into the provider talent's `utility` effect for the raid-dps profile (`effects/<game>/<class>.manual.json`) and into `scorer/loops/<class>.json`. Simulations of the community's models, not measurements; the beneficiary counts are assumptions. Do not hand-edit.
