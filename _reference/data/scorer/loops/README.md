# Spec loops: why the community takes what it takes

The scorer values a talent by what it does to damage, healing, threat, mana, survivability and a small
utility credit. That misses talents whose job is structural: they make the spec's *loop* work (Improved
Blizzard), keep it safe (Improved Frost Nova, Ice Block), or are simply the cheapest legal path to a deeper
talent. This folder closes that gap.

## Files

- `audit.md` — generated by `loop_audit.py`: every talent a Classic community build takes that the model values
  under 0.4%/point (and every hand-draft talent the Forever optimizer dropped), with the documented role from
  the loop files when there is one. **OPEN** rows are talents nobody has explained yet.
- `<class>.json` — per spec model: `purpose` (what the spec is for), `loop` (the rotation/cycle), `constraints`
  (the facts the loop depends on), and `talents` — for each talent the audit flagged: `role`, `why` (quoted
  from a guide where the fetch returned it, otherwise the community reasoning in our words), `encoded` (how the
  reason is expressed in `effects/<game>/<class>.manual.json`) and `sources` (guide URLs).

## Roles

| Role | Meaning | How it is priced |
|---|---|---|
| enabler | the loop does not work without it (Improved Blizzard, Unleashed Fury for a pet tank) | damage/survivability on the loop's sources, sized from the loop (e.g. "the second Blizzard lands") |
| control | keeps the loop running: positioning, snares, hit on packs (Improved Frost Nova, Elemental Precision on 8 mobs) | survivability plus the damage the control protects |
| safety | emergencies and deaths (Ice Block, Cold Snap, defense/armor talents) | survivability, weighted by the profile's death share |
| throughput / sustain / utility | ordinary damage, mana, raid buffs | parsed or manual numbers as before |
| filler | cheapest legal path to a deeper talent; the model may pick a different filler with the same score | left at its face value and documented so the audit stops flagging it |
| avoid | harms the loop (Frostbite scatters an AoE pack) | negative value in that profile |

## Process

1. `python _reference/data/scorer/loop_audit.py` — read `audit.md`; every OPEN row is a research item.
2. Find the reason in Classic guides (Icy Veins / Wowhead / Warcraft Tavern; decode calculator links when the
   prose is silent — `mage/talents/classic-baseline/builds.json` `aoe-grinding-frost-deep` came from one).
3. Record it in `loops/<class>.json`. If the reason is mechanical, derive a number from the loop and put it in
   the manual effect file **for both games** — the reason carries over to Forever when the talent is unchanged,
   and scales when it is not (Forever Improved Blizzard chills 45% instead of 65%, so its enabler value is ×0.7).
4. Re-run the Classic calibration for that spec (`run.py ... --game classic-era --compare <build>`); the
   community core must come back. Then re-run the Forever profiles.

## What the first pass changed (2026-09-16)

- Mage AoE: Improved Frost Nova, Permafrost, Improved Blizzard, Arctic Reach, Cold Snap, Ice Block, Ice Barrier,
  Frost Warding, Elemental Precision priced from the pack cycle; Frostbite negative for AoE; Shatter's AoE value
  cut to the Nova window (~17% of Blizzard ticks). Two Classic reference builds added (Icy Veins 19/0/32, Warcraft
  Tavern 7/0/44 with Shatter).
- Tanks: Toughness and Anticipation priced from armor/defense arithmetic (with Icy Veins' caveat that neither is
  as good as it looks); Improved Devotion Aura as tank + group value.
- Warriors: Unbridled Wrath (dual wield), Tactical Mastery (stance dancing), Anger Management (1 rage / 3s).
- Mana-bound raid specs (Hunter, Elemental, Balance, Shadow, Retribution, Mage, Warlock): per-spec raid mana
  weight so Efficiency / Convection / Benediction are priced as the guides treat them.
- Pet tanks (Hunter, Warlock leveling): pet damage counts as pet threat (`pet_dmg_to_surv`).
- Leveling cats: Claw replaces Shred as the builder (`profile_overrides`), so Savage Fury/Ferocity count.
- Druid: Nature's Grace also hastens heals (the Regrowth/Nature's Grace resto build).
