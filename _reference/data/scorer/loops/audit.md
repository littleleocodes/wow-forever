> Generated by `_reference/data/scorer/loop_audit.py`. Value = score lost per point when the talent is removed from the full build (leveling: fraction of time per kill; raid: DPS/HPS/threat score). Talents under the threshold are flagged: the community takes them for a reason the model does not encode. Resolve each flag in `loops/<class>.json` (role, rationale, source) and the manual effect files.
