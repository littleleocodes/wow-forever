# Local patches to the ElliotWood/Forever fork (archived 2026-10-18: the fork was deleted; not applied any more)

`setup.py` builds the ElliotWood/Forever wowsims fork unchanged except for the files in `patches/forever/`, which it copies over the
clone before every build (`--rebuild`, `--update`, first setup), and the edits listed in `patches/forever/edits.json`: insertions after
a unique anchor (`after` + `insert`) and replacements of a unique text (`replace` + `with`, since 2026-10-08). An update (`--update`)
resets the patched files to the fork's version first, so `git pull` stays clean, and applies the patches again.
