plans (`_reference/data/characters/professions.py`). Per recipe spell: `SkillLine` (197 Tailoring, 333 Enchanting, 185 Cooking, 171
Alchemy), `TrivialSkillLineRankLow` (the recipe turns yellow) and `TrivialSkillLineRankHigh` (grey); green from halfway between. In
Forever `MinSkillLineRank` is 1 for every recipe, and the user's mage knows recipes Classic's trainers taught only at a higher skill
(Spidersilk Boots and Bolt of Silk Cloth, Classic 125, known at 106): a trainer's requirement is server data no file here holds.
